# Page Objects

Generate your Page Object classes here (Module 4, Lab 14):
- `TaskFormPage.ts` — wraps the task form locators and actions
- `TaskListPage.ts` — wraps the task list locators and actions

Locators must use `getByTestId()`. Open the React components in
`web-app/src/components/` first so Copilot reads the real `data-testid` values.
